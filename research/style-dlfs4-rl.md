# 风格档案：斋藤康毅《深度学习入门4：强化学习》（dlfs4-rl）

> 用途：给「从零构建 LLM」交互式中文教程提供一份**可直接照做**的"斋藤式"写法参照，并为 GRPO / PPO / DPO 等章节提供精确的"如果你读过鱼书4……"锚点。
> 读者：本教程负责写作、设计、搭建交互组件的 agent。
> 这本书是用户点名的**首要参照**，所以本档案读得最深：第 1 章与第 9 章逐字通读，附录 D 逐页看图。

- **页码换算**：正文的**印刷页码 = PDF 页码 − 19**（例：p.239 = PDF p258）。前言用罗马页码，i–vi 对应 PDF p14–19。下文写 "p.N" 时指印刷页码。
- **阅读覆盖**
  - 逐字通读：前言、**第 1 章全章**、**第 9 章全章**（每页公式都看了图）、**附录 D 全文**（看图）、后记。
  - 精读：3.1（贝尔曼方程推导的"先准备、再推导"节奏）、5.2.3（反向计算收益）、5.5（异策略与重要性采样）、7.1–7.4（DeZero、神经网络、one-hot、`unchain`）、8.4.3（Dueling DQN 与优势函数）、10.1–10.2（A3C/A2C、DDPG、TRPO/PPO）、10.5（离线 RL、模仿学习、MDP 建模建议）。

  - 图、式、代码文件的数量按编号最大值统计。

## 2. 模式目录（Pattern catalog）

每条模式写四项：**做法**、**位置与示例**（引文不超过 2 句）、**网页化改编**。

### P1 用"上一章卡在哪里"开篇（限制驱动的章节衔接）
- **做法**：每章开头先复述上一章方法的前提，再指出它在什么情况下失效，本章正是为此而来。全书由此串成一条问题链：手算只适用于直线形的回溯图（ch3）→ 联立方程规模一大就算不动（ch4）→ DP 需要环境模型（ch5）→ MC 必须等回合结束（ch6）→ 表格存不下 10^123 个状态（ch7）→ 从基于价值转向基于策略（ch9）。
- **示例**：第 5 章开篇（p.117）："在第4章中，我们使用DP得到了最优价值函数和最优策略。但要使用这个方法，环境模型（状态迁移概率和奖励函数）必须是已知的。" 第 6 章开篇（p.153）："不过，蒙特卡洛方法只能在达到回合的终点时更新价值函数。"
- **网页化**：每章首屏放一张"上一章的局限"卡片，配一个**能跑的失败演示**。例如：bigram 模型用不上长上下文，由此引出 attention；没有 KV cache 时生成时间随长度平方增长，由此引出 KV cache。卡片最后一句写"本章要解决的就是这个"。

### P2 章节骨架：引言 → 若干组（推导 → 算法 → 实现）→ 横向比较 → 小结
- **做法**：章首写 2–3 段引言（不用要点列表），然后是若干 X.Y 节。一个算法通常拆成"推导/思路 → 算法 → 实现"三个 X.Y.Z 小节，之后有一节横向比较或讲优缺点，最后是小结。
- **示例**：第 9 章依次是 9.1 最简单的策略梯度法（9.1.1 推导 / 9.1.2 算法 / 9.1.3 实现）、9.2 REINFORCE（算法 / 实现）、9.3 基线（思路 / 带基线的策略梯度法）、9.4 Actor-Critic（推导 / 实现）、9.5 基于策略的方法的优点、9.6 小结。第 1 章依次是分类（1.1）、问题（1.2）、算法（1.3）、实现（1.4）、变体（1.5 非稳态）、小结（1.6）。
- **网页化**：侧栏目录给每个小节标上固定的三种图标（推导 Σ、算法 ⟳、实现 </>），读者一眼就知道现在是在"讲道理"还是"写代码"。实现小节默认展开可运行的代码单元。

### P3 引入新概念的五步法（最核心的教学手法）
- **做法**：
  1. 用一句设问提出问题；
  2. 先举一个**领域外、能手算**的玩具例子（考试分数、骰子、骰子加硬币、老虎机期望）；
  3. 用几行 NumPy 打印结果；
  4. 回到 RL 公式，把玩具例子的结构映射过去，并明确写出"结构相同"；
  5. 再给一个本领域的直观场景。
- **示例**：基线（9.3）。先算三人考试 90/40/50 的方差 466.67，再减去各自的历史均分，方差降到 32.67。书里的结论是："如本例所示，我们可以通过对某个结果减去预测值的方法来减小方差。预测值的精度越高，方差就越小。"（p.253）然后给出式 9.4，再讲 CartPole"杆子即将倒下"的状态：G=3，V=3，权重为 0（p.254）。另一个例子在 3.1.1：先用骰子（期望 3.5）和"骰子+硬币"（期望 2.35）预演 Σπ·p·r 的结构，p.63 明确点出两者结构相同。
- **网页化**：每个新概念配一个**玩具沙盒**（不涉及 LLM、数字能手算、浏览器里直接跑），再配一段"同构映射"动画，把玩具里的元素逐个移到 LLM 公式里对应的位置。例如"考试分数"移到"同一 prompt 下 G 个回答的奖励"，"历史均分"移到"组均值"。

### P4 先手算，再用代码核对
- **示例**：p.183："它的导数是 dy/dx=6x，代入x=5，结果是30。的确与上面的结果一致。" 再如 p.8 先手算出老虎机 a、b 的期望 1.05 和 0.95；p.186 先揭晓 Rosenbrock 函数的最小值 (1,1)，再让梯度下降去找。
- **网页化**：这正是用户要求的"处处可最小化验证"。做成"**预测 → 运行 → 对照**"组件：读者先填预测值（或做选择题），点运行后组件显示 ✓/✗ 和差值。每个组件附一行本地验证命令（`uv run …`）。CI 把所有组件的期望值当作测试来跑。

### P5 用虚拟值单独测试一个机制
- **示例**：p.12 `reward = np.random.rand() # 虚拟的奖励`；p.245 `G = 100.0  # 虚拟权重`，接着 `J = G * F.log(prob); J.backward()`，输出是 `prob: variable(0.49956715)`。
- **网页化**：做成"探针单元"，把一个量（比如 G 或 advantage）做成滑块，实时显示梯度和概率怎么变。例如把 advantage 从 −2 滑到 +2，看某个 token 的概率被推高或压低。这很适合作为 GRPO 一节的第一个交互。

### P6 公式与变量的对照清单
- **示例**：p.245 原话："作为参考，下面对照列出了上面的代码中出现的变量与相应的数学式。" 随后列出 `prob` ↔ πθ(A0|S0)，`G` ↔ G(τ)，`J` ↔ G(τ) log πθ(A0|S0)。
- **网页化**：KaTeX 公式里的每个符号和代码里的变量**双向高亮**，鼠标悬停在任一侧，另一侧随之发光；移动端改为点按弹出。

### P7 代码按"差分"演进
- **做法**：同一个文件骨架反复出现，新算法只列出改动的方法，没变的部分用 `...` 省略。
- **示例**：p.250："REINFORCE的代码与9.1节中的代码基本相同，不同之处只有Agent类的update方法。下面仅列出了不同部分的代码。" 从 `simple_pg.py` 到 `reinforce.py`，改动只有一处：把 `loss += -F.log(prob) * G` 移进反向循环。
- **网页化**：代码块提供"与上一版对比"开关，用 diff 视图只高亮改动行。`Agent` 骨架全书保持同名同结构，让读者形成肌肉记忆。

### P8 带圈编号注释 ①②③
- **示例**：p.21 的主循环写成 `# ①选择行动`、`# ②实际去玩，获得奖励`、`# ③从行动和奖励中学习`，正文随后按 ①②③ 逐条解释。p.258 的 actor_critic 写成 `# ①self.v的损失`、`# ②self.pi的损失`。
- **网页化**：①②③ 做成可点击的锚点。点正文里的 ②，代码对应行高亮；点代码行，正文对应段落高亮。

### P9 固定顺序"代码 → 输出结果 → 逐行解释 → 图"，并明确处理随机性
- **做法**：
  - 代码块右上角有文件名标签。
  - 紧跟一个带下划线标签的"输出结果"，长输出用 `...` 截断。
  - 然后逐行解释，需要时再给图。
  - 随机性要显式处理：要么固定种子（`avg.py` 里有 `np.random.seed(0)`），要么用提示框说明。
- **示例**：p.24 的提示框说，如果用 `np.random.seed(0)` 固定随机数种子，"那么每次得到的结果都是相同的"。
- **网页化**：每个代码单元都必须带"期望输出"，用固定种子预先跑出，并在 CI 里校验。含随机性的单元要显示种子，并提供"换个种子"按钮。输出区标题沿用"输出结果"。

### P10 单次运行与多次平均并列
- **示例**：p.24："在比较强化学习算法时，由于随机性的存在，因此在大多数情况下得知单次实验的结果是没什么用的。" 图 1-14 叠加了 10 次运行，图 1-16 是 200 次平均；图 9-4 和图 9-11 都是左图单次运行、右图 100 次平均。
- **网页化**：学习曲线组件带"运行次数"滑块（1 到 100），实时显示均值曲线和阴影带。GRPO 的训练曲线（不同 seed）也照此处理。

### P11 用参数扫描代替习题
- **示例**：p.27："这里尝试了3个ε值：0.01、0.1和0.3。" 随后解释：0.3 探索过度，0.01 探索不足。1.5 节比较了样本均值和固定 α=0.8 两种更新方式。
- **网页化**：把参数扫描做成滑块或多选，曲线叠加显示。书中的解释放进"看完图再展开"的折叠框，鼓励读者先自己解释。

### P12 推导逐行写、右侧括注理由；长证明放附录，给"难点"留出口
- **示例**：p.241："本章省略了它的推导过程，只给出了作为结果的式9.1。D.1节详细介绍了推导过程，如果你对此感兴趣，可以参考一下。" 附录 D.1 每一步右侧都括注理由：（展开期望值）（将∇θ移动到Σ中）（积的微分）（∇θG(τ)永远为0）（乘以Pr/Pr）（log梯度的技巧）。
- **网页化**：做一个"推导步进器"，逐行展开，每行带理由标签，还能"数值验证这一步"（比如在 3 个动作的 softmax 上检查 E[∇log π]=0）。长证明放进可折叠的"附录"抽屉，默认收起，但链接要醒目。

### P14 公式卡与"编号谱系"
- **示例**：
  - 3.6 小结用【贝尔曼方程】【贝尔曼最优方程】【最优策略】三个标签列出公式；1.6 并列样本均值和指数移动平均两条增量式。
  - 9.6 用 Φ_t 统一四种算法：(1) G(τ)、(2) G_t、(3) G_t − b(S_t)、(4) R_t + γV(S_{t+1}) − V(S_t)。书中写道："期待(1)→(2)→(3)→(4)这样的编号一直延续下去，从而有更高级的方法出现，产生更好的结果。"（p.262）
- **网页化**：做一个贯穿 RL 部分的 **"Φ_t 家谱表"** 组件。(1)–(4) 原样引自鱼书4，后面由本教程续写：(5) GRPO 的组相对优势，(6) PPO-clip（比率加裁剪），以及 DPO（离线学习，没有显式的 Φ_t，用 log-ratio 构成隐式奖励）。每一行都能展开看公式、代码 diff 和方差小实验。

### P15 两种提示框：鸟形"补充"和蝎形"注意"

- **人称**：正文里"我们"出现约 480 次，是绝对主语；"你"约 40 次，只用在描述读者的体验或选择时（"你将体会到……""如果你对此感兴趣……"）。"读者"一词几乎只出现在前言和后记。

## 4. 概念锚点

### 4.1 第 9 章讲法逐步拆解（GRPO / DPO 一节的地基）

下面每条都可以直接改写成"如果你读过鱼书4……"。

1. **动机**（p.239）：到目前为止的 Q 学习、SARSA、MC 都属于**基于价值的方法**：先给价值函数建模，再"借助"它得到策略（鸟形提示框补充了通用策略迭代）。不借助价值函数、直接给策略建模、并用梯度优化策略的方法，叫**策略梯度法**。本章的路线写得很清楚：从最简单的策略梯度出发，一路推到 REINFORCE、带基线的 REINFORCE、Actor-Critic。
2. **记号**（p.240）：
   - 随机性策略 π(a|s)；θ 表示"把神经网络的所有参数排成一列的向量"，用神经网络建模的策略记作 πθ(a|s)。
   - 这里设的是**目标函数**而不是损失，用梯度**上升**求最大值。鸟形提示框补充说：把目标函数乘以负数就能当损失用。
3. **轨迹与回报**（p.240）：τ = (S0, A0, R0, S1, A1, R1, …, S_{T+1})；G(τ) = R0 + γR1 + γ²R2 + … + γ^T R_T。
   - ⚠ **下标约定**：鱼书4 把行动 A_t 之后得到的奖励记作 **R_t**，而 Sutton–Barto 记作 R_{t+1}。本教程要选定一种并注明。
4. **目标函数**（p.241）：J(θ) = E_{τ~πθ}[G(τ)]。鸟形提示框解释了为什么下标只写 πθ：τ 的生成也取决于环境 p(s'|s,a) 和 r(s,a,s')，但我们能控制的只有策略。
5. **式 9.1**（p.241）：∇θJ(θ) = E_{τ~πθ}[ Σ_{t=0}^{T} G(τ) ∇θ log πθ(A_t|S_t) ]。推导留到附录 D.1。更新规则是梯度上升：θ ← θ + α∇θJ(θ)。
6. **MC 近似**（p.241–242）：采样 n 条轨迹取平均；取 n=1 得到**式 9.2**，本章都以它为准。图 9-1 把每一项 G(τ)∇log πθ(A_t|S_t) 画在对应的 (S_t, A_t) 下面，用的是回溯线形图的符号。
7. **直观意义**（p.242–243）：由 ∇log πθ = ∇πθ / πθ 可知，它和 ∇πθ 方向相同，即"在状态 S_t 下采取行动 A_t 的概率增加最快的方向"，G(τ) 是这个方向的权重。书里举例：收益是 100，这一回合里采取的行动就以 100 倍的权重被增强。原话是："也就是说，在顺利的情况下，在此之前采取的行动会相应地增强。反之，在不顺利的情况下，在此期间采取的行动会相应地减弱。"
8. **实现**（`ch09/simple_pg.py`，p.243–247）：
   - 策略网络：`Linear(128) → ReLU → Linear(action_size) → softmax`。p.244 当场讲了 softmax 公式，强调输出都在 0 到 1 之间、合计为 1，所以"可以作为概率使用"。
   - `Agent` 的超参数：γ=0.98，lr=0.0002，优化器 Adam；`memory` 里存 `(reward, prob)`。
   - `get_action` 用 `np.random.choice(len(probs), p=probs.data)` 采样，**返回的 `probs[action]` 是仍连着计算图的 Variable**。这是实现上的关键：概率先存起来，回合结束后再一起反传。
   - 先用虚拟权重 `G=100.0` 演示 `J = G * F.log(prob); J.backward()`，然后列出公式与变量的对照（见 P6）。
   - `update` 先用一个反向循环算出 G，再用**另一个循环**累加 `loss += -F.log(prob) * G`。所以每一步用的都是**同一个 G(τ)**（从 t=0 起的总回报），这正是式 9.2。
   - 蝎形提示框（p.246）："对于这个例子，我们可以将目标函数J(θ)乘以-1所得到的-J(θ)作为损失函数，此时可以通过梯度下降法的最优化方法（SGD、Adam 等）更新参数。"
   - 结果：CartPole-v0 跑 3000 个回合，单次运行剧烈波动，100 次平均也到不了上限 200。
9. **REINFORCE**（9.2，p.248–251）：
   - **因果论证**："反过来说，采取某个行动之前获得的奖励与该行动的好坏无关。" 权重 G(τ) 包含了 t 之前的奖励，相当于混入了噪声。改用 **G_t = R_t + γR_{t+1} + … + γ^{T−t}R_T**，就得到**式 9.3**。
   - 书中没有证明，参考文献是 Spinning Up 的 "Intro to Policy Optimization" 和 "Proof for Don't Let the Past Distract You"。
   - 鸟形提示框：两者都是无偏的，但式 9.1 的方差更大。
   - 代码 diff：把 `loss += -F.log(prob) * G` 移进反向循环。
   - 名字的由来提示框：REINFORCE 是 "REward Increment = Nonnegative Factor × Offset Reinforcement × Characteristic Eligibility" 的首字母缩写。
   - 结果：100 次平均接近 200。
10. **基线**（9.3，p.251–254）：
    - 考试例子：方差从 466.67 降到 32.67。
    - **式 9.4**：∇θJ = E[ Σ (G_t − b(S_t)) ∇θ log πθ(A_t|S_t) ]，b(S_t) 可以是**任何只以 S_t 为输入的函数**（证明见附录 D.2）。
    - 实践中常用价值函数 b(S_t) = V_{πθ}(S_t)，但真正的价值函数未知，所以还得训练它。
    - 直观例子是 CartPole 即将倒下的状态（图 9-8）。原话："由于权重是0，因此无论选择什么行动，采取那个行动的概率都不会变大，也不会变小。"
11. **Actor-Critic**（9.4，p.254–259）：
    - 先用韦恩图（图 9-9）说明基于价值和基于策略的交集；带价值基线的 REINFORCE 已经同时属于两边。
    - **式 9.5**：用神经网络 V_w 当基线，ω 表示它的参数。
    - 式 9.5 的问题是 G_t 必须等回合结束才能算。图 9-10 对比 MC 和 TD 后，用 TD 把它改成**式 9.6**：Φ_t = R_t + γV_w(S_{t+1}) − V_w(S_t)。
    - V_w 用 TD 目标的均方差来训练。鸟形提示框解释了 Actor（行动者）就是策略，Critic（评论者）就是价值函数。
    - 代码 `ch09/actor_critic.py`：`PolicyNet` 和 `ValueNet` 都是 128 个隐藏单元；`lr_pi=0.0002`，`lr_v=0.0005`；两个 Adam 优化器；每一步都更新。
      - ① `target = reward + gamma * v(next_state) * (1 - done)`，然后 `target.unchain()`，`loss_v = MSE(v, target)`；
      - ② `delta = target - v`，然后 `delta.unchain()`，`loss_pi = -F.log(action_prob) * delta`。
12. **基于策略的方法的三个优点**（9.5，p.260–261）：
    - 直接对策略建模；
    - 能处理连续行动：网络输出正态分布的均值和方差后再采样（图 9-13）；
    - 用 softmax 时行动概率**平滑变化**，不像 ε-greedy 的 argmax 那样会突然切换。
13. **统一公式**（9.6，p.262）：∇θJ = E[ Σ Φ_t ∇θ log πθ(A_t|S_t) ]，其中
    - (1) Φ_t = G(τ)
    - (2) Φ_t = G_t
    - (3) Φ_t = G_t − b(S_t)
    - (4) Φ_t = R_t + γV(S_{t+1}) − V(S_t)

    此外 Φ_t 也可以取 Q(S_t, A_t)（证明见 [18]）或**优势函数** A(S_t, A_t) = Q(S_t, A_t) − V(S_t)。
14. **附录 D**（p.304–307）：
    - D.1：展开期望、把梯度移进求和号、乘积求导、乘以 Pr/Pr，得到 **log 梯度的技巧**（log-derivative trick）。再把 Pr(τ|θ) 分解为 p(S0) Π πθ(A_t|S_t) p(S_{t+1}|S_t, A_t)，与 θ 无关的环境项求梯度后为 0。
    - D.2：由 Σ_x Pθ(x) = 1 两边求梯度，得到 E_{x~Pθ}[∇θ log Pθ(x)] = 0（式 D.2）。
    - D.3、D.4：把 b(S_t) 放进期望里依然为 0。
    - 蝎形提示框："行动A_t的变化会导致收益G_t的变化，因此以下式子不成立。" 那个式子就是 E[G_t ∇log π] = 0。也就是说，**基线绝不能依赖 A_t**。
15. **第 10 章的延伸**：
    - A2C 同步更新，把各环境的状态拼成一个批次，一块 GPU 就能算；网络共享主干，策略头和价值头分开（图 10-3）。
    - DDPG 的提示框（p.270）："在图10-7中，假设根据随机性策略对行动进行采样，那么反向传播就会在进行采样的地方停止（在此之后，传播的梯度都是0）。"
    - TRPO/PPO（p.271）："策略梯度法的问题在于，虽然根据梯度可以知道参数更新的'方向'，但不知道'步幅'，也就是前进多少合适。" TRPO 用 KL 散度不超过阈值作为约束，但需要海塞矩阵，计算量大；PPO 是它的简化。**书中没有给出 PPO-clip 的公式**，这部分需要本教程补上。

### 4.5 易混淆点清单（书中的蝎形提示框 + 本档案发现的坑）

1. **符号方向**：目标函数用梯度上升，损失 = −J（p.246）。要讲清 `loss = -logp * A` 里的负号从哪来。
2. **基线不能依赖行动**：E[G_t ∇log π(A_t|S_t)] ≠ 0（p.307）。组均值包含自身的影响见 4.2。
3. **G(τ) 与 G_t**：`simple_pg.py` 先用一个循环算出 G(τ)，再在另一个循环里给所有步都用这个 G(τ)；`reinforce.py` 在反向循环里同时累加 G_t 和 loss。这两段代码长得几乎一样，很容易看错。建议用 diff 视图展示。
4. **奖励下标**：鱼书4把 A_t 之后的奖励记作 R_t，Sutton–Barto 记作 R_{t+1}。本教程统一一种，并在首次出现时注明。
5. **`unchain` 的语义**：书里（p.210）的理由是"避免不必要的计算"，但如果不停止梯度，梯度本身就变了（会变成 residual-gradient；在 Actor-Critic 里，策略损失的梯度还会流进价值网络）。这是需要**加强解释**的地方。
6. **q(s,a) 中的 a 与 π 无关**（p.69）：先自由选一次行动，之后再按 π 行动。这对理解优势函数 A=Q−V 很关键。
7. **非稳态与"状态随行动变化"不是一回事**（p.36）。LLM 里对应的区别是：分布随训练漂移，与生成过程中前缀在变化，是两件事。
8. **确定性策略 μ 与随机性策略 π**（p.108）：argmax 解码 与 采样解码。
9. **随机种子**：书中 5.5 的重要性采样示例没有设种子，打印的方差（10.63、2.48、0.27）只是一次抽样；对应的精确方差是 10.14、2.56、0.41（附录 A）。本教程所有示例都要固定种子，并同时给出精确值。
10. **train/eval 模式与比率**（本档案读 dlfs6 代码时发现）：PPO/GRPO 的比率 πθ/πθ_old 默认两边是"同一个函数"。但 dlfs6 的 GRPO 里，`model` 带着 dropout 求概率，`old_model` 不带，所以即使权重相同，比率也不等于 1。教程讲比率时要么关掉 dropout，要么把这一点明确讲出来（这也是"最小验证"很容易翻车的地方）。

PPO-clip 的桥接检查（有限差分，同样已运行）：

```python
import numpy as np
sm = lambda t: np.exp(t - t.max()) / np.exp(t - t.max()).sum()
def clip_obj(th, th_old, a, A, eps=0.2):
    r = sm(th)[a] / sm(th_old)[a]; return min(r*A, np.clip(r, 1-eps, 1+eps)*A)
def ngrad(f, th, h=1e-6):
    return np.array([(f(th+h*e) - f(th-h*e)) / (2*h) for e in np.eye(len(th))])
th0, a, A = np.array([.2, -.5, 1.]), 2, .75
print(ngrad(lambda t: clip_obj(t, th0, a, A), th0), A*(np.eye(3)[a] - sm(th0)))  # 两者相同
th1 = th0 + np.array([0, 0, .6])                                                 # 比率约 1.222 > 1+eps
print(ngrad(lambda t: clip_obj(t, th0, a, A), th1))                              # [0 0 0]
```

- 考试方差 466.6667 → 32.6667。
- E[score] = 0。

- 1.5 指数移动平均：α=0.8 时各奖励权重为 0.8、0.16、0.032……，加上初值 Q0 的权重后合计为 1。
