## 0. 速览：十条可以直接照做的规则

1. **先摆问题，再给改进。** 每节开头说清上一版哪里不行，结尾用实验确认改进有效（§7.4、§8.1）。改进分大小："Reverse / Peeky 是小改进，Attention 是大改进"。
2. **每个概念走同一组台阶。** 依次是：类比或动机 → 玩具数字 → 5 行 NumPy（打印 shape）→ 计算图（正向 + 反向）→ 封装成层类 → 接入模型 → 实验。
3. **形状是第一语言。** 张量一律标 `(N, T, H)`，反向传播的公式也靠"形状检查"推出来（图 1-26）。
4. **正文只讲差异代码。** 完整实现放在仓库里，正文贴关键片段，注明文件路径，未展开的部分写 `# 参照源代码`。新类继承上一章的类，只改几行。
5. **有疑问就做实验。** 一个问题配一段可运行代码和一张图（印225）。失败的例子和挑过的例子也要照实说（印165）。
6. **数学要省着用。** 第 7 章没有编号公式，第 8 章只有 1 个；推导放进附录，或者指给前作。
7. **难点不让读者跳过。** 说"有点复杂，我们一步一步来"或"不懂也没关系，跑一下代码就明白了"，不说"可以跳过"。
8. **旁注只有两种。** "提示"（鸟，正文和附录共 108 处）和"注意"（蝎子，72 处），平均每 2 页一个。全书没有"专栏"，也没有习题。
9. **章首和章末各有固定结构。** 章首是题词，加一段"回顾 + 目标"；章末是一段散文小结，加"本章所学的内容"要点框和下一章预告。题词会在正文里再次出现。
10. **语气是同行者。** 主语用"我们"，句子短，多设问，用生活类比，偶尔冷幽默。新术语第一次出现时加粗（中文版印成蓝色），后面括注英文。

## 2. 模式目录（Pattern catalog）

### 2.0 章骨架（按第 8 章还原，其他章同构）

```
第 N 章 标题
  题词（名言 / 电影 / 小说 / 论文标题，常带双关，后文会呼应）
  衔接段：上一章做到了什么 → 本章要解决的问题和目标 →（"让我们一起进入……的世界吧！"）
  N.1 机制：问题 → 小改动 → "某种计算"占位 → 关键障碍 → 关键想法 → 玩具数字 → NumPy → 计算图 → 层类
  N.2 组装：继承上一章的类，只改几行；给出层结构图
  N.3 评价：toy 数据集 → 训练代码 → 终端输出截图 → 学习曲线 → 和 baseline 对照 → 可视化与解释
  N.4 其他话题：变体、实现上的选择、易错点
  N.5 应用 / 前沿窗口：简化的论文结构图 +"核心我们已经学会了"
  N.6 小结：2–3 段散文 + 下一章预告
  【本章所学的内容】6–7 条要点（浅蓝底框）
```

下面每个模式给出**做法**、**出处与例句**、**网页化**三部分。

### P1. 章首题词，正文呼应
- **做法**：每章用一句题词开场，多和本章主题构成双关，正文或小结会再提到它。第 5 章的题词取自《我是猫》开篇段落，为第 7–8 章的翻译例句"吾輩は猫である"埋下伏笔；同一句话的日文原文在图 8-1 里又被当作"很长的输入句"（印322）。
- **出处与例句**：第 6 章题词"卸下包袱，轻装上阵。——尼采"，到 §6.2.4 遗忘门变成"只有放下包袱，才能轻装上路。"（印236）。第 8 章题词"注意力是全部。——Vaswani 们的论文标题"（印321），章末收在"今后Attention 自己也将吸引更多的'注意力'。"（印373）。
- **网页化**：章首放一张"题词卡"；正文呼应处加一个小锚点，悬停提示"呼应章首题词"。题词可以选 LLM 史上的论文标题或名言，但必须和本章机制有关。

### P2. 衔接段：回顾 → 目标 → 邀请
- **做法**：章首 2–3 段固定三拍：上一章完成了什么（一句话），本章要解决的问题与目标，邀请读者出发。
- **出处与例句**："本章的目标是在代码层面理解Attention 的结构，然后将其应用于实际问题，体验它的奇妙效果。"（印321）
- **网页化**：章首组件包括三部分。一是"上一章你已经做到"，可以点回去复习；二是"本章目标"清单，和章末"本章所学"逐条对应、可以勾选；三是预计时长和"是否需要 GPU"徽章。

### P3. 问题驱动的改进链，像连载故事一样推进
- **做法**：前言建议"像读连载故事一样"按顺序读，遇到问题先解决，再改进。章内用"改进①②③"编号推进，并区分大改进和小改进。
- **出处与例句**：§4 开头先列出两个瓶颈，并预告"（4.1 节解决）""（4.2 节解决）"（印131）；§7.4 讲 Reverse / Peeky；§8.1.2–8.1.5 依次是"编码器的改进""解码器的改进①②③"。例句："上一章我们已经对seq2seq 进行了改进，但那些只能算是'小改进'。下面将要说明的Attention 技术才是解决seq2seq 的问题的'大改进'。"（印322）
- **网页化**：每节顶部放"问题卡"，尽量现场复现失败（例如句子变长后准确率下降）。节末放"改进 diff"，高亮代码差异。侧栏用"改进轨迹"时间线，展示同一个指标（loss / 困惑度 / 正确率）随每次改进的变化。

### P4. 概念阶梯（以 Attention 为范本）
- **做法**：
  1. 类比：西装塞进衣柜。
  2. 人类直觉："我们在进行翻译时，大脑做了什么呢？"
  3. 用一个"某种计算"层占位。
  4. 指出障碍：选择操作不可微。
  5. 关键想法：全选，取加权和。
  6. 玩具数字：`a = 0.8, 0.1, 0.03, 0.05, 0.02`。
  7. NumPy：先 `T, H = 5, 4` 并 `print(shape)`，再写批处理版 `(N, T, H)`。
  8. 计算图，反向传播直接复用第 1 章的 Repeat / Sum 对偶。
  9. 封装成层类 WeightSum → AttentionWeight → Attention → TimeAttention。
  10. 接入解码器，做实验。
- **出处与例句**："这个思路就是，与其'单选'，不如'全选'。"（印328）
- **网页化**：做一个"概念阶梯"组件。左侧是台阶导航（类比 / 数字 / 代码 / 图 / 层 / 实验），每一级配一个最小可运行单元；两级之间用一句话说明"为什么需要下一级"。

### P5. 先讲"为什么"，把障碍说出来
- **做法**：前言把"为什么这个方法更好、为什么有效、为什么有问题"列为本书特色。引入机制之前，先点出约束，比如"选择不可微""one-hot 乘法其实只是取行""编码结果是固定长度"，让后面的设计显得不得不如此。
- **出处与例句**："不过这里有个问题，就是选择（从多个事物中选取若干个）这一操作是无法进行微分的。"（印327）
- **网页化**：用"障碍框"（红色左边线）写约束，紧接着用"想法框"（绿色）给关键想法。可以配一个"不这样做会怎样"的反事实实验按钮，例如用 hard argmax 做选择，演示梯度全为 0。

### P6. 形状检查是贯穿全书的思考工具
- **出处**：§1.1.5（印7–8）、图 1-8 / 1-9；图 1-26 用形状推出 MatMul 的反向传播（印33）；§5.3 的图 5-18；第 8 章每个变量都标了 `(N,T,H)`（图 8-11、8-15、8-16）。

### P7. 代码规范 + 乐高式层库 + 继承扩展
- **做法**：§1.2.2 规定所有层都有 `forward()`、`backward()` 以及 `params`、`grads`。可复用的层逐步沉淀到 `common/`。后面的章节通过继承只改差异，例如 `AttentionEncoder(Encoder)`、`AttentionSeq2seq(Seq2seq)`、`RnnlmGen(Rnnlm)`（印278、344–347）。
- **例句**："通过这种模块化，可以像搭建乐高积木一样构建网络。"（印14）
- **网页化**：常驻一个"工具箱"侧栏，列出已经实现的层和函数，并链接到首次出现的章节。用"继承 diff 视图"只显示新增或覆盖的方法。DLFS6 用的是 PyTorch `nn.Module`，可以把这条规范改写成"forward + parameters()"；凡是需要手写反向传播的地方，都用 `torch.autograd.gradcheck` 或数值梯度验证。

### 4.3 读者容易卡住、本教程应该加强的地方（附验证）

1. **奇异值 vs 谱半径（印227–228）。** 书里说：最大奇异值小于 1 时梯度会指数级减小；大于 1 时"很可能"指数级增加，并补了一句"必要条件，并非充分条件"。但书里自己做的梯度消失实验（`Wh = 0.5*randn`，`seed=3`）中，**最大奇异值是 1.330，大于 1，梯度依然消失**，因为这时**谱半径是 0.628**。（另一个实验 `Wh = randn` 的最大奇异值是 2.659、谱半径 1.255，梯度爆炸。）建议教程这样写：
   - σ_max < 1 是梯度消失的**充分条件**，因为每一步都有 ‖dh·Wᵀ‖ ≤ σ_max‖dh‖。
   - 长期的增长率由谱半径 ρ 决定。
   - 用一个滑块同时显示 ρ、σ_max 和范数曲线。
   - （附录 A 已验证。）
2. **Q/K/V 的命名映射。** 书中第 8 章的 h 就是 query，hs 同时充当 key 和 value，而且没有 W_Q、W_K、W_V 投影，也没有 1/√d。DLFS6 ch02 的讲法是从"软字典"出发，再讲缩放（`01_soft_dict.py`、`03_attn_scaling.py`）。教程应该画一张对照图，把两种讲法对上。
3. **训练用软选择，推理用 argmax，两者不要混。** 第 8 章说"选择不可微，所以用加权和"，这是训练时的做法。生成时又用 argmax 做贪婪解码（图 7-18），或者按概率采样（§7.1）。读者常把"softmax 是 argmax 的可微近似"和"解码策略"搞混。
4. **"错一位"和 teacher forcing。** 书中只在代码和旁注里出现（印213、印296、印301），没有起名字。GPT 预训练用的是同一个错位，值得单独讲一节，并做成可视化。
5. **padding mask 和因果 mask 不是一回事。** 第 7 章明确说不处理 padding mask（印289）。图 8-37 的 Self-Attention 也没提解码时不能看到未来。本教程必须专门讲因果 mask，对应 DLFS6 `ch02/06_attn_mask.py`。
6. **广播里藏着 Repeat。** 广播相当于一个看不见的 Repeat 节点，它的反向传播是 Sum（印29、印331）。这是手写反向传播时 shape bug 的主要来源，而 autograd 把它藏起来了。可以用一个"广播 → Sum 回来"的小单元演示。（附录 A 已验证 Repeat 与 Sum 的对偶。）
7. **困惑度和 loss 的换算。** 困惑度 = exp(平均交叉熵)。如果对 V 个词均匀猜测，困惑度就是 V（附录 A 已验证）。建议把训练日志里的 loss 实时换算成困惑度，并配一句人话解释（P9）。
8. **中译本里正文和代码不一致的一处（印268）。** 正文说"当它比之前的困惑度（best_ppl）低时，将学习率乘以1/4"，但代码 `if best_ppl > ppl: ... else: lr /= 4.0` 是在**没有改进时**才降低学习率。这正好说明"以代码为准、做最小验证"的必要；教程里出现学习率衰减时可以顺手提一句。
9. **Attention 和 Peeky 的最终精度相近（图 8-26）。** 书里断言序列越长 Attention 越占优（印353），但没有做实验。可以在 GPU 上做一个"按序列长度扫描"的实验来补上。

### 5.3 图解语法（Diagram grammar）

- **层结构**：圆角矩形，层名用英文（Embedding、LSTM、Affine、Softmax with Loss、Time XXX），**从下往上**堆。数据流用细灰箭头；跨时间步展开时横向排开。

```python
"""对《深度学习进阶》中将被本教程引用的命题做最小数值验证（只依赖 NumPy）。"""
import io
import sys

import numpy as np

sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding="utf-8")
rng = np.random.default_rng(0)
results = []


def check(name, cond):
    results.append(bool(cond))
    print(("PASS " if cond else "FAIL ") + name)


def num_grad(f, x, eps=1e-6):
    g = np.zeros_like(x)
    for i in np.ndindex(x.shape):
        old = x[i]
        x[i] = old + eps
        fp = f()
        x[i] = old - eps
        fm = f()
        x[i] = old
        g[i] = (fp - fm) / (2 * eps)
    return g


def softmax(s):
    e = np.exp(s - s.max(axis=-1, keepdims=True))
    return e / e.sum(axis=-1, keepdims=True)


# §1.3.4（印28-30）、印332：Repeat 的反向传播是 Sum，Sum 的反向传播是 Repeat
x, dy = rng.standard_normal((1, 4)), rng.standard_normal((3, 4))
check("Repeat 的反向传播是 Sum",
      np.allclose(num_grad(lambda: np.sum(np.repeat(x, 3, axis=0) * dy), x), dy.sum(0, keepdims=True)))
x2, dy2 = rng.standard_normal((3, 4)), rng.standard_normal((1, 4))
check("Sum 的反向传播是 Repeat",
      np.allclose(num_grad(lambda: np.sum(x2.sum(0, keepdims=True) * dy2), x2), np.repeat(dy2, 3, axis=0)))

# §1.3.5.3（印38-39）：Softmax with Loss 的梯度是 (y - t) / N
S, t = rng.standard_normal((5, 7)), np.eye(7)[rng.integers(0, 7, 5)]
check("Softmax with Loss 的梯度 = (y - t)/N",
      np.allclose(num_grad(lambda: -np.sum(t * np.log(softmax(S))) / 5, S), (softmax(S) - t) / 5, atol=1e-6))

# 附录 A：sigmoid' = y(1-y)，tanh' = 1 - y^2
z, h = rng.standard_normal(6), 1e-6
sig = lambda v: 1 / (1 + np.exp(-v))
check("sigmoid' = y(1-y)", np.allclose((sig(z + h) - sig(z - h)) / (2 * h), sig(z) * (1 - sig(z))))
check("tanh' = 1 - y^2", np.allclose((np.tanh(z + h) - np.tanh(z - h)) / (2 * h), 1 - np.tanh(z) ** 2))

# 图 3-8（印100）/ §4.1：one-hot @ W 等于取 W 的对应行；Embedding 反向要累加（印136-137）
W, idx = rng.standard_normal((7, 3)), np.array([1, 0, 3, 0])
check("one-hot @ W == W[idx]", np.allclose(np.eye(7)[idx] @ W, W[idx]))
dout = rng.standard_normal((4, 3))
g_true = num_grad(lambda: np.sum(W[idx] * dout), W)
dW_add = np.zeros_like(W)
np.add.at(dW_add, idx, dout)
dW_write = np.zeros_like(W)
dW_write[idx] = dout  # 书中"不太好的方式"
check("Embedding 反向：np.add.at 正确，直接写入在 idx 重复时出错",
      np.allclose(g_true, dW_add) and not np.allclose(g_true, dW_write))

# §8.1.3-8.1.4（印329-338）：加权和的三种写法一致；注意力权重是概率分布
hs, a = rng.standard_normal((5, 4)), np.array([0.8, 0.1, 0.03, 0.05, 0.02])
check("加权和：repeat+sum == a @ hs",
      np.allclose(np.sum(hs * a.reshape(5, 1).repeat(4, axis=1), axis=0), a @ hs))
hsb, hq = rng.standard_normal((10, 5, 4)), rng.standard_normal((10, 4))
aw = softmax(np.sum(hsb * hq.reshape(10, 1, 4), axis=2))  # 内积打分 + Softmax
check("注意力权重非负且每行和为 1", (aw >= 0).all() and np.allclose(aw.sum(1), 1))
check("批处理加权和：广播+sum == einsum",
      np.allclose(np.sum(hsb * aw.reshape(10, 5, 1), axis=1), np.einsum("nt,nth->nh", aw, hsb)))

# §5.5.2（印211-212）：困惑度 = exp(平均交叉熵)；单个数据时 = 1/p
check("困惑度：p=0.8 -> 1.25，p=0.2 -> 5",
      np.isclose(np.exp(-np.log(0.8)), 1.25) and np.isclose(np.exp(-np.log(0.2)), 5.0))
check("均匀猜 V=10000 个词时困惑度 = 10000", np.isclose(np.exp(-np.log(1 / 10000)), 10000))

# §4.2.6（印153）：unigram 分布取 0.75 次方，0.01 -> 约 0.026
p = np.power([0.7, 0.29, 0.01], 0.75)
check("负采样分布：0.01 -> 约 0.026", abs((p / p.sum())[2] - 0.0265) < 1e-3)

# §6.1.3（印225-228，ch06/rnn_gradient_graph.py）：梯度爆炸/消失，以及奇异值与谱半径
for scale, kind in ((1.0, "爆炸"), (0.5, "消失")):
    np.random.seed(3)
    Wh = np.random.randn(3, 3) * scale
    dh, norms = np.ones((2, 3)), []
    for _ in range(20):
        dh = dh @ Wh.T
        norms.append(np.sqrt(np.sum(dh ** 2)) / 2)
    smax = np.linalg.svd(Wh, compute_uv=False).max()
    rho = np.abs(np.linalg.eigvals(Wh)).max()
    print(f"     scale={scale}: 最大奇异值={smax:.3f} 谱半径={rho:.3f} 范数 {norms[0]:.3f} -> {norms[-1]:.6f}")
    grew = norms[-1] > 100 * norms[0]
    check(f"梯度{kind}（scale={scale}）", grew if kind == "爆炸" else norms[-1] < 0.01 * norms[0])

# §6.1.4（印228-229）：梯度裁剪只缩放长度、不改方向
grads = [rng.random((3, 3)) * 10, rng.random((3, 3)) * 10]
total = np.sqrt(sum((g ** 2).sum() for g in grads))
before = [g / total for g in grads]
rate = 5.0 / (total + 1e-6)
if rate < 1:
    for g in grads:
        g *= rate
after = np.sqrt(sum((g ** 2).sum() for g in grads))
check("梯度裁剪：总范数变为 max_norm 且方向不变",
      np.isclose(after, 5.0, atol=1e-4) and all(np.allclose(g / after, b) for g, b in zip(grads, before)))

print(f"\n{sum(results)}/{len(results)} 通过")
sys.exit(0 if all(results) else 1)
```
